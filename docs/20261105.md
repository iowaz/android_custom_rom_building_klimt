an upstream refresh and for fixes of everything the 2026-11-04 runtime log review of 20261104 found, then an
independent review before the build. No flash is authorized by this build task.

kernel-prebuilt are at the heads of their branches (unchanged).

`prepare.py patch` rebased the device patches of four projects Evolution X had moved (hardware/interfaces,
frameworks/native, vendor/lineage, frameworks/base) with `git am -3`, without conflicts, on its first real run
(device `ecbf7fc`).

## Review

Independent review by Codex CLI (`gpt-6.1-sol`, reasoning high), read-only, on exported diffs and context:
`diagnostics/builds/20261105/review/` (`BRIEF.md`, `CODEX_REVIEW.md`, `REVIEW_DISPOSITION.md`). Four should-fix
findings, all accepted. The first SystemUI patch stopped the animators, which left an empty view, and it did not
read the initial doze state. Two verifier checks were too weak. Checking the first finding showed that patch
would also have cancelled animators on ScrimUtils' background thread, which throws. The patch was rewritten.
