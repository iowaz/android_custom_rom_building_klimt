the baseline. STG covers all 9,273 retained symbols across vmlinux and those modules and reports no type
differences. Twenty-five assembly/alias exports without DWARF types additionally have unchanged declaration
and implementation proofs. The compiled 688-byte pkvm_module_ops and nine callback argument layouts match.

unresolved mtk_drm_gateic_set_backlight is retained. The generated import/export protection headers match.

against all 888 baseline packaged instances still gives zero CRC mismatches and that same one unresolved symbol.

The pipeline now requires frozen-source kernel identity, named hash-bound source/type/pKVM/config/module
evidence, a seven-day control freeze and mechanical emitted rollback/security equality. The latter compares
all AVB rollback/chain/security metadata, boot/init_boot v4 OS fields and actual/reported patch levels.
Readiness seals the build/verifier tooling separately from preparation's original tooling record. The final
pre-build suite has 68 passing tests; baseline regression retains all 195 historical and 112 metadata checks.
