## Behavior

The original upstream 24-hour check runs when the TrickyStore screen resumes; it is not a
background timer. That entry point now uses the same persisted deadline as the background
service when monitoring is enabled. Monitoring off retains the original daily screen check
and the validated legacy hourly official refresh, which preserves user-imported keyboxes.
A system-owned timer is still required to deliver checks while Settings is closed.

Manual verification shows the existing checking label and an indeterminate progress bar.
Periodic screen refreshes retain that state until the asynchronous operation completes.
A completed manual check resets the next deadline to completion plus the selected interval,
including an offline result, and removes queued automatic checks that would repeat it.

Intervals are 15, 30 and 45 minutes, and 1, 4, 12 and 24 hours. The default remains one hour;
monitoring remains opt-in. An existing two-hour selection migrates to four hours. The
interval list, normalization and notification defaults are shared by Settings and the service.

Notification options are:

- Every completed check, regardless of result.
- Only an expired, revoked or suspended keybox, whether recovery succeeds or fails.
- Only an expired, revoked or suspended keybox whose recovery fails (default).

There is one final notification per qualifying check, including manual status checks while
monitoring is enabled. A successful replacement retains the original verdict for notification
policy and context. An unknown/offline result stays unknown. Technical failure codes remain
in the local diagnostic report; user-facing operation failures and notifications are localized.
The feature has explicit en-US and pt-BR resources, with English fallback for other locales.

Validated official replacement, the private rolling backup, serialized operations, bounded
network work, stale-write guards, RKP/off/missing-keybox pauses and absence of automatic data
clears are retained. The earlier 17 patches must remain byte-for-byte unchanged; this revision
adds one personal framework patch and one personal Evolver patch.
