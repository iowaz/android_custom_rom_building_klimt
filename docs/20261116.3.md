## Cause of the 20261116.2 failure

Evolution X commit `c90f7fc gms: Bring back AmbientStreaming` adds `AmbientStreaming.apk` as a Git LFS pointer,
but `vendor/gms/.gitattributes` has no LFS rule for that path. Git treats the 130-byte pointer as a normal file,
so every checkout contains the pointer text and `aapt2 dump badging` fails. The upstream tip was unchanged when
checked (2026-11-16). All other LFS projects in the tree (chromium-webview prebuilts, vendor/xiaomi/klimt and the
other seven gms files) are materialized.

every 30 minutes.

Attempt01 started 2026-11-16 14:57 and compiled in about 1h28m (Ninja 18,050 actions, ZIP at 16:25). The initial

`recheck01` then stopped with exit 3, "Packaged kernel differs from audited vmlinux-derived Image". This was an
operator error, not a kernel defect: with `--tool-review`, `verify.py` takes the reviewed-readiness path and does
not apply the attempt's `release-audit-update.json`, so it compared the `-ab20261116.3` kernel with the carried
20261113.3 `vmlinux` (`-ab20261113.3`). A recheck after a carried-kernel build must pass the attempt's own sealed
release audit to `tool_review.py --kernel-audit`. recheck01's duplicate ZIP (hash equal to `out/`) and extraction
scratch were removed, and the 20261113.3 ZIP was also moved to the C: archive with a junction.

`recheck02` (same ZIP, same tooling, attempt release audit) passed full verification at 18:07: all 195 historical
checks and the seven supplemental tracks (policy, patch packaging, private compatibility, Health, GMS/themes/apps,
