# 20261116

The owner requested a new build with every configured upstream synced (Evolution X, LineageOS, AOSP),
committed and pushed before the build starts, and the build started automatically without progress
polling. The installed phone remains on 20261113.3; this request does not authorize a flash.

## Source result

Evolution X manifest `8205ab60d004625bdc8393911f44e2a303ce3d78` was fetched and all configured projects
synced (63 projects changed since 20261113.3). AOSP remains at the manifest's `android-17.0.0_r1` tag; the
configured LineageOS `lineage-24.0` branches are refreshed. `external/zstd` was renamed by the manifest and
its old checkout was moved aside, not deleted. Two projects were added: `external/google-fonts/google-sans-flex`
and the Qualcomm `hardware/qcom-caf/sm8850/audio/mcs`, which is outside the MediaTek klimt build.

All 17 patches in 12 projects were kept. Eight patched projects moved upstream and were replayed and re-exported:
frameworks/native, lineage-sdk, Settings, Updater, bootable/recovery, frameworks/base, device/lineage/sepolicy
and Evolver. The other 16 patches applied as recorded or with a 3-way merge and keep their stable patch IDs.

One patch needed a hand port: frameworks/base `0003` (scheduled keybox monitoring). Upstream appended new
methods to the end of `IActivityManager.aidl` (DuckRKP state/provisioning and its own
`setSpoofTrickyStoreKeyBox` setter), so our `requestTrickyStoreKeyboxOperation` method was moved to the new
end of the interface. It stays last, which keeps the upstream Binder transaction numbers. The rest of the
patch applied unchanged. The upstream keybox setter and our monitor are separate methods with no name clash;
how the two interact on the phone has not been tested.

Device patch record commit is `3b7cac4`; the build label commit is `2644d06` (kernel `-ab20261116`).
The 30-step media volume, the product-scoped A2DP safeguard and the aconfig preflight are retained.

## Attempt

Sources, tags, this record and the snapshot were committed and pushed before launch. Attempt01 failed to
compile at about 8% (Ninja 1,916/22,151) and was then stopped (-15). No ZIP was produced.

Two errors, one cause: `ActivityManagerService` did not implement `requestTrickyStoreKeyboxOperation`, and
Evolver's `TrickyStore.kt` could not resolve `android.security.trickystore.KeyboxMonitor`. The hand-ported
frameworks/base `0003` contained only the `IActivityManager.aidl` hunk. `git apply --reject` had written the
other 13 files to the working tree but not the index, so the commit took the AIDL file alone. Those files were
then removed as leftovers. `export.py` checks that the exported patch reproduces the commit, not that the commit
matches the patch it replaces, so the loss was not caught before the build.

The source fix is [20261116.2](20261116.2.md). The `20261116` tags stay where they are as a record of this source.
